## 2. Delivered Surface

- `tethys-thread`: turn state machine (idle/running/interrupted/error, permission parking, replay dedup).
- `tethys-acp`: ACP v1/v2 client, committed fixtures, mock flow.
- `tethys-agent-servers`: connection store, leases, two-phase reaping, recovery ladder (cancel → force close → resume+replay → restart → Interrupted), ACP v2 profile support.
- `tethys-supervisor`: process-group containment, stderr ring buffer, SIGINT→grace→force escalation.
- `tethys-core`: thread create/prompt/cancel/resume/delete over the connection store.

## 3. Recorded Deviations

- **"2 repos" = two isolated work directories.** The concurrency test uses two temp workdirs (`repo-a`, `repo-b`) rather than two initialized git repositories. This was accepted as satisfying the criterion on 2026-09-19; the test still proves cross-vendor and cross-directory isolation.
- **ACP v2 build repaired 2026-09-19.** M1.4 added `AgentCompat::projection_target`; the feature-gated `mock_vendor` initializer was not updated, so `cargo test -p tethys-agent-servers --features acp-v2` failed with `E0063` and the v2 conformance path had never run green. The one-line fix makes all three `acp-v2` CI jobs pass.
- **Windows containment** uses `process-wrap` kill-on-close rather than a custom Job Object; covered by the same ladder tests on CI.
