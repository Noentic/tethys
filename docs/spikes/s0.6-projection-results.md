## 1. Context & Architecture

Per `ARCHITECTURE.md §11.3`, Tethys maintains a single canonical MCP configuration (`~/.tethys/mcp.json`) and projects it into native agent settings files so agents function identically whether invoked from Tethys or directly from the developer's terminal.

Target files:
1. **Claude Code:** `.mcp.json` / `~/.claude.json` (JSON)
2. **Codex CLI:** `~/.codex/config.toml` (TOML)
3. **OpenCode:** `opencode.json` (JSON)

Safety guarantees:
- Format-preserving modifications (retaining comments, table headers, and whitespace).
- Lossless rollback: removing a projected server returns the file to its exact previous state.
