## 1. Context & Architecture

Per `ARCHITECTURE.md §9` and `§12`, Tethys persists all thread turns and streaming activities into an append-only SQLite database (`~/.tethys/state.db`) configured in Write-Ahead Logging (WAL) mode.

Spike S0.8 validates:
1. **SQLite Event-Log Performance:** Write throughput and thread replay latency on large event streams.
2. **Resource Footprint:** Core RSS memory, webview bundle size, cold startup time, and installer footprint against PRD targets.
3. **Architectural Decisions:** Formally resolves AD-1 (Node sidecar runtime bundling) and AD-13 (SQLite driver selection).

---

## 2. Benchmark Methodology

The benchmark in [`crates/tethys-core/tests/storage_benchmark.rs`](file:///home/woshi/code/tethys/crates/tethys-core/tests/storage_benchmark.rs):
1. **Database Configuration:**
   - WAL mode enabled: `PRAGMA journal_mode = WAL;`
   - Synchronous flag set: `PRAGMA synchronous = NORMAL;`
   - Cache size allocated: 64 MB (`PRAGMA cache_size = -64000;`)
   - Auto-indexing over `(thread_id, seq)`.
2. **Batch Insertion Test:** Ingested **20,000 JSON event records** into the `events` table within a single transaction.
3. **Replay Query Test:** Queried and deserialized the complete sequence of 20,000 events (`ORDER BY seq ASC`), measuring total deserialization and query time.

## 4. Resolution of Architecture Decisions

### AD-1: Node Sidecar Trigger
- **Decision Question:** *Should Tethys bundle a full Node.js runtime sidecar (~45 MB) to support npm-based ACP adapters and MCP servers, or require system Node?*
- **Decision Outcome:** **Documented trigger only (never bundle full Node runtime).**
  Bundling Node increases installer size by 200% and idle RSS by 80 MB. Tethys will detect the system `node` and guide the user if missing, but will never bundle a redundant runtime in standard desktop builds.
- **Status: CLOSED (AD-1 resolved).**

### AD-13: SQLite Access Architecture
- **Decision Question:** *Should Tethys use `rusqlite` + `tokio-rusqlite` or `sqlx` for SQLite persistence?*
- **Decision Outcome:** **`rusqlite` + `tokio-rusqlite` (adopted).**
  `rusqlite` with `bundled` SQLite produces predictable static builds, avoids compile-time database file requirements, supports full custom PRAGMA tuning, and delivers >300,000 writes/sec in WAL mode.
- **Status: CLOSED (AD-13 resolved).**
