## 1. Context & Architecture

Per `ARCHITECTURE.md §7.5`, coding agents execute nested shell commands, compilers, and tool sub-processes. Without rigorous process group supervision:
1. Canceling a turn or killing an agent leaves worker sub-processes (such as background test runners or dev servers) running in the background.
2. Unbounded stderr output can exhaust memory during agent crashes or tight error loops.

Spike S0.3 implemented:
- **Process Group Isolation (`setpgid`):** Children are assigned a dedicated process group (`pgid = child.id()`).
- **Cancellation Ladder:** Graceful `SIGINT` (cooperative stop) $\to$ grace period timer $\to$ `SIGTERM` $\to$ `SIGKILL` sent to the entire process group (`libc::kill(-pgid, signal)`).
- **2 MB Stderr Ring Buffer:** Captures standard error output via bounded in-memory circular buffer.

## 2. Benchmark & Verification Methodology

The test suite in [`crates/tethys-core/tests/supervisor_kills.rs`](file:///home/woshi/code/tethys/crates/tethys-core/tests/supervisor_kills.rs):
1. **100 Forced Kills Stress Test:**
   - Iterated 100 times, spawning multi-process trees (`sh -c 'sleep 10 & sleep 10 & sleep 10 & wait'`).
   - Immediately called `force_kill_group()`.
   - Verified that the kernel completely reclaimed all PIDs in the group via `libc::kill(-pgid, 0)` (verifying ESRCH return).
2. **Cancellation Ladder Test:**
   - Spawned an agent catching `SIGINT`.
   - Exercised the timed escalation from `SIGINT` to `SIGTERM` and `SIGKILL`, confirming orderly shutdown.
3. **Stderr Ring Buffer Overflow Test:**
   - Wrote streaming bytes exceeding capacity and verified boundary clamp to exactly the buffer limit with FIFO byte drain.
