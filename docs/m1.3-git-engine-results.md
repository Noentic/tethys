## 2. Delivered Surface

- `tethys-git` (pure, synchronous): repo discovery, temp-index checkpoints with
  linked-worktree support, start/end refs, full-state restore with undo capture,
  CLI read layer, `DiffSource` anchor engine (imara-diff histogram + hunk cache),
  worktree lifecycle with bootstrap/setup runner, stage/unstage/hunk-discard/commit,
  archive and delete guards.
- `tethys-core`: thread→worktree registry, `ProjectGitConfig` loading from
  `<repo>/.tethys/config.json`, start/end checkpoints on `Running` edges, and
  `spawn_blocking` at the async boundary.
- IPC: 15 typed `git.*` commands (merge/push/pr_create remain `UNIMPLEMENTED`, M2.6);
  specta bindings regenerated.

## 3. Recorded Deviations

- **AD‑5 (reads):** M1.3 ships CLI-only reads behind `read.rs`; the gix port is
  deferred until profiling demands it (S0.4 measured 122 ms p95 for the CLI pipeline).
- **Watcher (U6):** live file-watch previews are cut; checkpoints always snapshot
  the full worktree, `changed_paths` remains an optional hint. M1.9 shipped the
  on-demand review surface without them (see `m1.9-review-ui-results.md`), so the
  watcher remains an M1.3 follow-up.
- **Setup script:** runs headless through the supervisor-bound runner until the
  visible terminal surface lands (M1.7/M1.8).
