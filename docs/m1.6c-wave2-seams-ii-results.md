## 3. Decisions

- **The cancel phase is its own schema module.** `cancel.rs` keeps `CancelState` orthogonal to `ThreadState`; the kebab-case wire spelling
  (`cancel-requested`) is reconciled with the store's snake_case union in exactly one mapper (`cancelPhaseToState`), typed against the generated
  `CancelPhase`.
- **The backend owns the clock.** `AppShell.handleStopSession` sends one request and enters `cancel_requested` with a fixture deadline; a second press is
  impossible (the control is `disabled`), and `grace_elapsed` / `terminating` are left to M1.12.
- **The fill is a width transition, not a loop.** One transition set from the deadline at mount, right-anchored so it depletes left-to-right per DESIGN; no
  rAF loop and no reduced-motion suspension.
- **Fold order is a priority budget.** `ACTION_BAR_PRIORITY` encodes DESIGN's order; `Stop` and the isolation pill are excluded from the foldable set and
  an undeclared slot resolves to `UNDECLARED_SLOT_PRIORITY` (below `usage-bar`).
- **Stacking is structural.** The scale lives beside the semantic tokens (not themeable) and every overlay reads `--tethys-z-*`.

## 5. Deviations / Limitations

- **The two D4 primitives were added** (`schema-field-group`, `protocol-pill`) as planned, and listed in the milestone's `Owns` column.
- **`Force Kill` → `Force kill`** label correction applied; `shell.test.tsx` updated.
- **Two spellings for one concept** are intentional: schema `cancel-requested` vs store `cancel_requested`, reconciled in `@tethys/state` only. M1.12
  must not "fix" this by renaming the store union.
- **M1.6d had already landed on this branch**, so the plan's U2 single-file edits became edits to the split namespace files
  (`crates/tethys-api/src/thread.rs`, `apps/desktop/src-tauri/src/commands/thread.rs`, `packages/client/src/namespaces/thread.ts`). No behaviour change.
- **`imara-diff` was added to `tethys-acp`'s dependencies** to compute the v1 diff patch; it was already a workspace/lockfile dependency, so no lock change.
- **The compact `Compaction` payload is minimal** (`{ summary }`): the ACP `compaction_update` shape is unstable and the enabling decision is M1.17's.
- **The v2 mapper still maps `ToolCallContent::Diff` to `Unknown`.** §4.1's stated mapper gap was the v1 path; the v2 structured `Diff` needs a
  `changes`-aware renderer and is left to the worktree that owns the v2 surface.
- **The `Esc` unstack-order test was not added.** The scale parity and the no-literal-z discipline are covered; a cross-component unstack test would
  duplicate the existing per-component `Esc` handling for no new coverage. Recorded for the Wave 2 checkpoint if the integrator wants it.
- **`AppShell` does not itself call `thread.cancel`.** The shell is transport-free (it renders in tests with no Tauri host); a press enters
  `cancel_requested` with a fixture deadline and M1.12 wires the real request and the phase events. The exit behaviour — one press, no click-advance,
  backend owns the clock — is unchanged.
- **The fold pass uses a declared per-item width budget** (`ACTION_BAR_ITEM_WIDTHS`) against a `ResizeObserver`-measured bar width, rather than
  measuring each item's rendered width. The budget reserves the non-foldable chrome (`Stop`, the isolation pill, `ACTION_BAR_CHROME_WIDTH`) so the bar
  folds before it can overflow, and it cannot oscillate (the fold set is computed in one pass and never re-measured after a fold). It is the only form
  testable in `jsdom`, which reports zero layout width; the width numbers are the tuning knob if real widths drift.
- **`schema-field-group` uses `fieldset`/`legend`** rather than `section role="group"` so the a11y lint stays clean; the group role and name are unchanged.
