## 4. Decisions

- **No TypeScript patch parser.** `git.diff_file` already returns structured
  hunks (`DiffHunk`/`DiffLine`), so the plan's "patch parser" scope is a
  normalizer over that wire shape, not a `diff --git` text parser.
- **Stage is path-level, discard is hunk-level.** The engine's asymmetry is
  real (`git.stage(paths)` vs `git.discard(source, hunks)`); the file header
  owns the stage toggle and each hunk owns a destructive `Discard`, so the two
  never look like the same control.
- **Word diff is client-side and lazy.** Intra-line ranges are not on the wire;
  the viewer computes the LCS only for visible paired cells and caches by pair,
  so the full-file row model never runs it (keeps first paint cheap).
- **`Draft with agent` rides `commands.expand`.** No new endpoint; the built-in
  `commit` command is expanded over the diff summary and the user edits the
  result before `Approve & Commit` (`git.commit`).
- **Highlight is a post-paint decoration.** Rows paint as plain monospace first;
  token spans overlay when the worker answers, and an unknown language or an
  unavailable worker returns plain text rather than blocking or erroring.

## 5. Deviations

- **`Draft with agent` command wiring.** `commands.expand` is the composer's
  surface (worktree C); this chunk uses the built-in `commit` command name and
  documents the swap point. The panel is client-injectable, so wiring the real
  command later is a fixture swap at the Wave 2 checkpoint.
- **The default `DiffSource` is `HeadWorktree`.** The exact source a turn
  resolves to is Core's (`fallback_source`); the panel accepts a `source` prop
  and defaults to HEAD↔worktree until the turn anchor is threaded through.
- **`packages/diff` gained `react`/`react-dom` dev dependencies** (the viewer
  imports `@tethys/ui` and JSX); `pnpm-lock.yaml` updated accordingly.
- **Restore targets the first turn's start.** The inspector slot passes only
  `sessionId`, so the panel cannot know the active turn number; `restoreTurn`
  builds `Checkpoint { turn: 1, phase: "Start" }` and is marked with a
  `ponytail:` comment. Threading the real turn anchor through the slot is the
  follow-up.
- **The capability fixture defaults to `git-remote`** until worktree F's
  resolver is wired (D12); the panel and pill take a `capabilityFixture` prop
  and every gate is verified against all four fixtures.
- **Live-during-turn previews are not part of M1.9.** The M1.3 watcher remains a
  follow-up (its results doc now says so); this surface reviews the
  checkpoint/live-anchor diff on demand, and the anchor model already accepts
  live sources (`HeadWorktree`, `TurnStartWorktree`) if the watcher lands.
- **`collapsedContext` covers a withheld whole file, not inter-hunk gaps.**
  The engine emits only the changed hunks (with their context lines) and no
  skipped-gap count, so the hunk-header-style collapsed row is used for a
  `collapsed`/`binary` file with a `Load file` affordance; the DESIGN
  `N unmodified lines` gap row needs a wire field and is left to follow-up.
- **p95 > p50 criterion.** The recorded number is p50; see §2 for the jsdom
  caveat.
