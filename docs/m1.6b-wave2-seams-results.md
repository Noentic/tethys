## 2. Delivered Surface

- **`tethys-schema`:** new `workspace` module — `WorkspaceCapabilities { vcs, restore, max_concurrent_sessions }`,
  `Vcs` (`none` / `git-local` / `git-remote { host }`), `GitHost` (`github` / `gitlab` / `other`),
  `PermissionMode` (`supervised` / `auto-edit` / `yolo`). `Vcs` is a kebab-tagged enum, so the
  TypeScript side is a discriminated union the badge maps exhaustively. Registered for codegen.
- **`tethys-api`:** `workspace.capabilities` typed stub on `TethysApi`, returning `UNIMPLEMENTED`
  until M1.16's resolver; wired through a typed Tauri command, `invoke_handler`, and
  `@tethys/client` (`workspace.capabilities(workspaceId)`). The §12.1 mapping comment now reads
  `workspace` (it said `project`).
- **`@tethys/ui`:** `WorkspaceSourceBadge` (`Git · GitHub`, `Git · GitLab`, `Git · local`,
  `Folder · no VCS`, plus a secondary `Remote` tag) on the `workspace-source-badge` tokens;
  `registerActionBarSlot` / `getAllActionBarSlots` beside the inspector registry;
  `ActionBar` renders registered slots in the left pill cluster and shows the isolation pill as
  the branch or a muted `no git`.
- **`@tethys/state`:** the four canonical fixtures (`git-remote`, `git-local`, `no-git`,
  `git-no-restore`) and `PERMISSION_MODE_LABELS`, keyed by the schema enum.

## 3. Decisions

- **AD‑15 resolved to the MVP inputs.** `vcs`, `restore` and `max_concurrent_sessions` are the
  resolved set; `isolation` and `forge_cli` stay V1 inputs (`architecture.md` §10.6) and are not
  in the struct. Every Wave 2 gate reads this one set rather than re-deriving VCS status.
- **`@tethys/ui` stays free of generated bindings.** `WorkspaceSourceBadge` takes a structural
  prop union; the schema→badge mapper owns the exhaustive switch. The only schema-typed lookup
  (`PERMISSION_MODE_LABELS`) lives in `@tethys/state`, which already depends on bindings, so a
  variant change is a compile error.
- **Action-bar slots render in the left pill cluster.** Usage and queue count keep their existing
  props; the registry exists for the pills M1.8 and later contribute. The hardcoded `Mode:` badge
  is left for M1.8 to replace when it registers its permission-mode pill.
- **`GitHost::Other` renders `Git · remote`.** `pages-views-spec.md` names only GitHub/GitLab/
  local/none; the fallback keeps the badge non-empty for any future host.

## 5. Limitations / Follow-ups

- `workspace.capabilities` returns `UNIMPLEMENTED`; M1.16 owns the real resolver
  (`crates/tethys-core/src/workspace/capability.rs`) and re-runs the four fixtures against real
  folders at the Wave 2 checkpoint.
- The badge's structural `Vcs` union could lag the schema silently; the M1.16 mapper's exhaustive
  switch is the guard. If that proves fragile, type the prop from `WorkspaceCapabilities["vcs"]`.
- The `no-git` isolation pill (`no git`) is rendered but not yet driven from capabilities; M1.16
  passes `noGit` from the resolved set.
- Drive-by: the `tethys-search` churn test's poll loop carried a dead initial binding that clippy
  flagged once CI ran `clippy` (CI only runs `cargo check`); removed in this branch.
