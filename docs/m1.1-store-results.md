## 2. Delivered Surface

- Versioned migrations (through `0003`/`0004` shared with later chunks), WAL pragmas, foreign-key cascade enforcement (`store_init_tests::fresh_database_creates_all_tables_and_pragmas`, `foreign_keys_enforce_cascade_and_reject_unknown_threads`).
- Append-only event log with monotonic contiguous sequences and `sinceSeq` replay reads.
- Materialized `entries` table so a thread opens without replaying its event history.
- BLAKE3 content-addressed blob store with deduplication and corruption detection.
- Sync-state tables (`projection_rows_round_trip`, `skill_rows_round_trip`).

## 3. Recorded Deviations

- **Benchmark criteria waived.** The 10k events/s and 50k-event scale criteria were never measured. Per the 2026-09-19 plan they are marked out of scope rather than evaluated; the functional no-replay proof remains the shipped evidence. Downstream budgets (M1.13 footprint, M1.7/M1.9 perf) rest on this unverified assumption and should be re-checked if they are ever exercised.
- **Real `SIGKILL` stress test is opt-in.** `kill_crash::test_real_sigkill_mid_write_leaves_no_torn_state` is `#[ignore]` by design (heavy subprocess stress); only the deterministic `crash_safety` tests run in CI.

## 4. Full Quality Gate Verification
