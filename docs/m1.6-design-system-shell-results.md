## 2. Delivered Surface

### `@tethys/ui`
- **Tokens & CSS variables**: 31 semantic color tokens, elevation layers, layout metrics (40px header, 48px rail, 56px action bar, 280px session column, 360px inspector pane), radii, and motion tokens conforming to `DESIGN.md` d0-rc2 and normalized to Tailwind v4 canonical syntax.
- **Component Primitives**: `Button`, `IconButton`, `ActionIconButton`, `Input`, `Textarea`, `Badge`, `KeycapPill`, `StatusDot`, `Tooltip`, `Popover`, `ModalDialog`, `Drawer`, `Listbox`, `ToggleSwitch`, `StepperInput`, `SegmentedControl`, `TabStrip`, `ApprovalInboxPill`, `Splitter`, `Skeleton`, `EmptyState`, `Toast`, `Chip`, `Row`, `SessionListRow`, `SessionGroupHeader`.
- **Session Chrome**: 7-state visual dot matrix (`running`, `paused`, `blocked`, `ready`, `completed`, `interrupted`, `error`) and optimistic aggregate daemon health dot.
- **Wave 2 Registry**: Type-safe registry for dynamic entry renderers (`registerEntryRenderer` / `getEntryRenderer`) with graceful fallback, and inspector slot extensions (`registerInspectorSlot` / `getAllInspectorSlots`).

### `@tethys/state`
- **Session Stores**: Isolated per-session stores (`Store<SessionState>`) backed by TanStack Store.
- **Patch Reducers**: Pure reducers applying Specta binding updates and handling history vs. live turn segmentation.
- **Batching & Stream Manager**: `SessionStreamManager` with requestAnimationFrame (rAF) batching, deduplication against `sinceSeq`, and subscriber fan-out.
- **Cancellation State Machine**: Structured 4-phase transition ladder (`idle` → `cancel_requested` → `grace_elapsed` → `terminating`).
- **Grouping Selectors**: 3-level pure aggregation selector (`Workspace → Provider → Session`).

### `apps/desktop`
- **App Shell**: 4-region layout with `WindowHeader`, `ActivityRail`, 3-column resizable workspace (`react-resizable-panels`), and `ActionBar`.
- **Window State & Unstacking**: Active window focus/blur tracking with surface dimming; hierarchical `unstackManager` managing Escape order (popover → drawer → palette → modal dialog).
- **Command Palette**: 600×400 modal palette built with `cmdk` offering filtered command sections (`Commands`, `Files`, `Actions`).
- **Route Shells**:
  - `/workspaces`: Hub catalog with responsive card grid, status filters, search input, skeleton loading, empty state, and 380px peek drawer.
  - `/thread/new`: Center prompt card (820px max, 12vh optical lift), model and workspace selector pills, and expandable session config panel.
  - `/thread/:id`: Active session stage wired to `@tethys/state` with action bar and inspector pane.
  - `/settings/*`: Settings layout with navigation sidebar, breadcrumb bar, and child routes (`general`, `providers`, `mcp`, `skills`, `keybindings`).

## 3. Recorded Deviations & Decisions

- **Tailwind CSS v4 Canonical Syntax**: All arbitrary property usages were normalized to Tailwind v4 canonical variable bindings (e.g. `bg-(--tethys-surface-panel)`, `border-(--tethys-hairline)`), avoiding deprecation and linter diagnostics.
- **No Foreign Component Runtimes**: Zero dependencies on foreign component runtimes (`@acp-components/*` is strictly treated as reference per ARCHITECTURE §5.2 and M1.6 plan D9).

## 4. Design Unification Pass (post-M1.6)

The shell shipped structurally correct but rendered flat and inconsistent. Findings and the standing rules that came out of them:

- **Geist was never loaded.** No `@font-face`, package, or asset existed, so the UI rendered in the system sans. It now ships via `@fontsource-variable/geist` and `geist-mono`, bundled as same-origin assets (the Tauri CSP has no `font-src`, so a remote font link would be blocked).
- **Tailwind never scanned `packages/ui`.** Auto-detection roots at the consuming app, so any class appearing *only* inside a primitive was never generated (toggle switches, stepper widths, selected-row accent bars all rendered unstyled). `tailwind.css` now declares `@source "./src"`.
- **`cn()` dropped type sizes.** `tailwind-merge` read `text-mono-micro` as a text *color* and removed it whenever a real color followed. The type scale is registered in `packages/ui/src/lib/utils.ts`; `utils.test.ts` pins it.
- **Spacing tokens shadow container sizes.** Defining `--spacing-lg` makes `max-w-lg` resolve to 16px, not 32rem, because Tailwind v4 checks `--spacing` before `--container`. Use `max-w-128` style numeric sizes; `token-discipline.test.ts` rejects the t-shirt names.
- **Elevation is now enforced.** `elevation.test.ts` asserts a perceptual (L*) gap on every pair of surfaces that abut, and that `tokens.css` and `manifest.ts` agree. The earlier ramp had `surface-rail == canvas` and Level 3 == Level 4.
- **`token-discipline.test.ts`** fails on raw palette colors, shadows, off-scale type sizes and weights, and any `--tethys-*` variable that `tokens.css` does not define (the latter would have caught `--tethys-accent-primary`, which left primary buttons on three routes with no background).
- New shared primitives: `Card`, `PageHeader`, `Select`, `UnderlineTabs`. Routes now compose these instead of hand-rolling inputs, cards and tabs.
- `StatusDot` gained provider/daemon health states (`healthy`, `auth_required`, `not_found`); previously the rail's daemon dot fell through to idle grey.
