## 6. Defects fixed during remediation

- Store schema-version tests lagged the new thread-metadata migration; the version is now a single test constant.
- Token-discipline test caught three undefined CSS custom properties and one `shadow-lg`; all now use manifest tokens.
- Provider pill had no accessible name when the hydrated provider name was empty.
- `threads.metadata` was added but `ThreadRecord` did not carry additional directories; now persisted and restored.
- The reader never merged `ConfigOptionsChanged` into the session's option cache, so a post-bootstrap `set_config_option` for a newly advertised option was rejected.
